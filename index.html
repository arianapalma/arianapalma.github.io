Lorem Ipsum

Lorem ipsum is the classic type of placeholder text. It is made to look like natural writing without having an actual meaning that readers need to focus on. Designers can use it to test things like fonts, spacing, paragraphs, and page layouts.

The original Lorem ipsum comes from a Latin text by the Roman writer Cicero. However, the modern version has been changed and rearranged over time, so it is not meant to be read as normal Latin.

Why Use Ipsum?

Ipsum is useful because designers usually need to see how a page will look before all of the final content has been written. Placeholder text fills empty spaces and makes it easier to test the design.

Different types of ipsum can also match the theme of a project. A food website could use Bacon Ipsum or Cupcake Ipsum, while a pirate-themed website could use Pirate Ipsum. The text does not have to be serious because its main purpose is to demonstrate how the finished content could fit into the design.
